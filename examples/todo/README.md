# TODO App 

It's a Todo app implementation using Castor!


## Stack

- Castor (runtime)
- [Templ](https://templ.guide/) (for UI components)

## Running

This application uses [Task](https://taskfile.dev/) as a automation tool. 

```shell
task ui // generate or update UI components

task dev // start the application
```

> Note: If you don't have Task installed, you can run the commands manually. See the `Taskfile.yml` file
